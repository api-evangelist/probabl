# Probabl

> Probabl (":probabl.") is the company behind scikit-learn. Its Skore Hub platform exposes a REST API at https://api.skore.probabl.ai (workspaces, projects, estimator / cross-validation / comparison reports, artifacts, goals, and OpenAI/Anthropic-compatible agent endpoints) and a remote MCP server at https://api.skore.probabl.ai/mcp. Authenticate with an `X-API-Key` workspace key (SKORE_HUB_API_KEY) or an OAuth bearer token.

Generated by API Evangelist on 2026-09-16 from the artifacts in https://github.com/api-evangelist/probabl — Probabl does not publish an llms.txt (docs.skore.probabl.ai/llms.txt and www.probabl.ai/llms.txt return 404).

## Agents
- [Skore Hub MCP server](https://api.skore.probabl.ai/mcp): streamable HTTP, one tool `skore_agent`, X-API-Key
- [scikit-learn Central MCP server](https://sklearn-central-mcp.probabl.workers.dev/mcp): experimental, 4 tools, no auth
- [Probabl Agent Skills](https://github.com/probabl-ai/skills): 14 data-science skills
- [skore-cli](https://github.com/probabl-ai/skore-cli): `skore skills`, `skore agent`, `skore sync`
